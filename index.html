About the course

Every week we read one paper. Before class, each participant picks a task: rewrite the abstract, critique the paper, redo a graph, reimplement an experiment, write the social media thread, find the papers it builds on, and more. Then we write it up here, so the work is useful to everyone who reads the paper after us.

You are welcome to experiment. Do the default thing, or try a new way that might fail. We encourage failure: learning only happens when you are exposed to the unknown.

Want to join? See the guide. Reading along from outside the class? Comments, corrections and follow-ups are welcome on GitHub Discussions.
