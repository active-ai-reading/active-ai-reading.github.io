Why Pretraining Fails to Share Cross-Lingual Knowledge

Adam Gaber, Uriel Dolev, Elisabeth Fittschen, Bobby Cheng, Yuval Marton, Leshem Choshen, 2026

arXiv PDF alphaXiv discussion Code
TL;DR Bilingual LLMs learn the same fact twice, once per language, and the cause is largely tokenization: two copies of English with disjoint token IDs already fail to share knowledge. Mapping Arabic words into English tokens (word-wise translation) makes knowledge transfer 14× better.

We read this paper together in the first class. Every post below was written as an example of what a task can look like, so you can copy its structure (and see how citations, figures, charts and code work on this site).
