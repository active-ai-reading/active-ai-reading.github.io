This guide is empty on purpose: it is yours to write. Some questions to start from (answer them, replace them, ignore them):

- How do you decide which figure to redo, and what is wrong with the original?
- Which tools did you use, and what would you use next time?
- How do you get the underlying numbers when the paper doesn't give them?
- What did you try that didn't work?
