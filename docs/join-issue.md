**Title:** 👋 Join here: comment to get access

**Body:**

Welcome to **Active AI Reading**!

**To join:** comment on this issue (just say hi). Your GitHub username is attached to your comment automatically.

Someone already in the course will add you, and you'll get an email invitation from GitHub. Accept it, and you can edit everything in the repository.

**Then:** follow the 10-minute start in the [README](https://github.com/active-ai-reading/active-ai-reading.github.io#start-here-10-minutes): add your profile, claim a task, write your first post.

---

**Already in the course? Help someone join:**

1. Repository **Settings → Collaborators and teams → Add people**
2. Type their GitHub username (from their comment) and choose the **Admin** role (so they can add the next person too)
3. React 👍 to their comment so others know it's done

No GitHub account yet? Make one at https://github.com/signup first.
