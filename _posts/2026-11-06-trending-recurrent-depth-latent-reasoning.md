## Papers worth knowing

1. **[Dory1.0-4B: A Looped Normalized-GPT](https://arxiv.org/abs/2611.03998)** (2026): Introduces a 4-billion-parameter recurrent language model that uses elastic depth, difficulty-aware loop allocation, and reinforcement learning to improve reasoning performance while reducing generated tokens.

2. **[Latent Reasoning in Continuous Space for Unified Multimodal Models](https://arxiv.org/abs/2610.42149)** (2026): Introduces LARC, a framework that enables multimodal models to perform reasoning directly in continuous latent space, improving image generation quality and enabling test-time compute scaling.

3. **[Learning When to Think Aloud in Latent Reasoning](https://arxiv.org/abs/2611.06108)** (2026): Introduces VITAL, a hybrid reasoning framework that selectively generates important intermediate tokens while performing the remaining reasoning in latent space, improving the balance between reasoning accuracy and token efficiency.
